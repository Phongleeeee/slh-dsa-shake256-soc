# Software

Sản phẩm phần mềm chính nằm trong `sphincs_signer/` và dùng đúng cấu hình
**FIPS 205 SLH-DSA-SHAKE-256f**. Bộ ký SPHINCS+ submission cũ không còn là
sản phẩm phát hành chính.

Executable chính: `sphincs_signer/build/slh_dsa_shake_256f.exe`.

Xem `sphincs_signer/README.md` để tạo khóa DPAPI, ký, xác minh, benchmark và
chạy 104 vector NIST ACVP.
